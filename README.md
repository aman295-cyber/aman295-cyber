**Tech:** Python · OpenCV · NumPy

[![Explore OpenCV Projects](https://img.shields.io/badge/Explore-OpenCV_Projects-5C3EE8?style=for-the-badge&logo=github)](https://github.com/aman295-cyber/OpenCV--projects)

A machine learning project exploring student stress-level prediction using academic, lifestyle and questionnaire-related features. Includes classification experiments and a Streamlit interface.

**Tech:** Python · Pandas · Scikit-learn · Streamlit
